## هدف پروژه

ساخت یک Loading Screen حرفه‌ای با قابلیت‌های:
- پنل تنظیمات کامل در WordPress Admin
- انیمیشن 3D لوگو
- سیستم Particle واقعی از Shape لوگو
- Progress Bar مستقل
- Fallback برای دستگاه‌های بدون WebGL
- سازگاری کامل با Elementor
- Performance بالا و Minimum Overhead
